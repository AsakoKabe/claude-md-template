# CLAUDE.md — шаблон

Шаблон `CLAUDE.md` для проектов с Claude Code. Общие части — правила поведения, правила работы, агенты — готовы как есть; всё проектное стоит в `<угловых скобках>`.

## Как подключить
1. Скопировать `CLAUDE.md` в корень проекта:
   ```bash
   gh api repos/AsakoKabe/claude-md-template/contents/CLAUDE.md --jq .content | base64 -d > CLAUDE.md
   ```
2. Заменить каждое `<…>` и удалить HTML-комментарии с подсказками; проверка — `grep -n '<' CLAUDE.md` пуст.
3. Удалить секции, которых у проекта нет: `Инварианты`, `Маршруты API`, предметные.
4. Оставить в таблице Agents только агентов, которые есть в `.claude/agents/` или `~/.claude/agents/`.

## Стиль
- Порядок секций не меняется; язык — язык проекта.
- Списки и жирные метки, без абзацев; пункт может быть длинным, если держит один факт с причиной.
- Пути, идентификаторы и команды — в обратных кавычках.
- Только верхний уровень: что видно из кода, сюда не копируется. Цель — меньше 200 строк.
